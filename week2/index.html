데이터 수집과 임베딩 분석

1주차는 브라우저의 claude.ai만으로 충분했습니다. 2주차부터는 작업대가 내 PC로 내려옵니다 — 이번 주는 전 과정을 Cowork(데스크톱 앱)에서 진행하며, 산출물은 전부 내 PC 폴더의 파일로 남습니다. 웹에서 데이터를 모아 폴더에 쌓고(크롤링), 텍스트를 의미의 좌표(임베딩)로 바꾼 뒤, 클러스터링과 차원축소로 한 장의 지도를 그립니다. 강의는 시작에 오늘 만들 것을 킥오프하고, 강의안을 따라간 뒤, 완성된 결과를 시연으로 확인하는 흐름으로 진행합니다. 아래 자료를 순서대로 열어 따라가시면 됩니다.

2주차 강의자료

수집에서 계보도까지 — 하나의 파이프라인, 7개의 자료

①②는 도구를 내 PC에 세팅하고 크롤링의 판단 기준을 세우는 과정, ③④⑤는 Cowork로 데이터를 모아 임베딩으로 바꾸고 지도로 그리는 실습 파이프라인, ⑥은 이번 주에 반복한 절차를 스킬 파일로 저장하는 법, ⑦은 같은 파이프라인을 논문 데이터에 얹어 네트워크를 그리는 과정입니다. 앞 자료의 산출물이 뒤 자료의 재료가 되므로 순서대로 보시는 것을 권합니다.

01

Chat · Cowork · Claude Code 개념 설치

1주차는 브라우저의 claude.ai면 충분했지만, 2주차부터는 산출물이 파일이라 작업대가 내 PC로 내려옵니다. 세 작업대의 차이와 주차별 배치(이번 주는 전 과정 Cowork, 3주차부터 Claude Code)를 이해하고, 데스크톱 앱 · 크롬 확장 · Claude Code를 설치해 작업 폴더 연동까지 확인합니다.

③–⑥ · Claude 데스크톱 앱(Cowork)에서 실행 · 산출물은 내 PC 폴더에
03

실습 — Cowork로 웹 스크래핑 실습

복사–붙여넣기 수백 번 대신 요청 문장 하나로 웹 데이터를 모아 연동한 내 폴더에 CSV와 본문 파일로 저장합니다. 베스트셀러 239권 수집부터 판결문 895건 사례까지, 수집 직후의 탐색적 분석(EDA)을 실제 수집 기록으로 따라갑니다.

→ 04

임베딩 추출 파이프라인 개념 실습

판결문 347건을 4,096차원 벡터로 바꿉니다. 임베딩이 무엇인지, OpenRouter로 모델을 어떻게 고르는지, API 키를 어떻게 안전하게 다루는지를 실제 실행 기록으로 배웁니다.

→ 05

판결문 347건의 지도 실습

클러스터링으로 다섯 개의 사건 유형을 찾고, 차원축소로 4,096차원을 한 장의 2D 지도로 만듭니다. 페이지 안의 지도는 실제 데이터이며, 직접 점을 눌러 탐색할 수 있습니다.

→ 06

나만의 스킬 만들기 실습

이번 주 내내 반복한 절차("요지를 훑고, 고른 사건은 전문을 읽고 답하라" 등)를 SKILL.md 파일 한 장으로 저장합니다. 관련 질문이 올 때마다 AI가 알아서 같은 절차로 움직입니다 — 강사가 7년 치 컬럼으로 만든 실제 스킬 사례까지.

2주차부터는 브라우저가 아니라 내 PC에서 실습합니다. ①번 자료에 설치 방법이 단계별로 나와 있으니, 강의 전에 미리 해두면 실습 시간을 온전히 쓸 수 있습니다.

🖥 Claude 데스크톱 앱 + 작업 폴더 claude.ai/download에서 설치하고 1주차와 같은 계정으로 로그인. 이번 주 산출물이 쌓일 폴더(예: 바탕화면/week2)를 만들어 Cowork에 연동합니다. ①번 자료 §3 참고.
🧩 Claude in Chrome (크롬 확장) 스크롤·클릭해야 내용이 나오는 동적 사이트를 수집할 때 씁니다. 크롬 웹스토어에서 설치 후 같은 계정으로 로그인. ①번 자료 §3에서 설치하고, ②번 자료(크롤링 이론)에서 왜 필요한지 배웁니다.
💻 Claude Code 설치 3주차부터 본격 사용하지만 이번 주에 미리 설치합니다. 터미널에 명령 한 줄이면 끝나고, Pro 이상 구독 계정으로 로그인해 추가 비용 없이 씁니다. 설치 후 "파이썬 버전 확인해줘"까지 해보세요. ①번 자료 §4 참고.
