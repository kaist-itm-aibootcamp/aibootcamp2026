WEEK 2 · STEP 4 — 도구의 지형

같은 Claude, 세 개의 작업대 —
Chat · Cowork · Claude Code

지금까지의 수집·임베딩·클러스터링은 모두 Cowork에서 실행했습니다. 그런데 곧 이어질 실습(내 PC에서 검색 서버 켜기)에는 Claude Code가 필요합니다. 왜 도구를 갈아타는지, 세 작업대의 차이부터 정리하고 설치까지 미리 끝내 둡니다.

1

세 개의 작업대 — 무엇이 다른가

셋 다 같은 Claude 모델과 대화하지만, AI의 손발이 어디에 놓여 있는지가 다릅니다. 손발의 위치가 할 수 있는 일을 결정합니다.

CLAUDE CHAT

브라우저 속 대화 상대

  • 실행 위치: 없음 — 대화와 문서 생성 중심
  • 파일: 업로드한 것만 읽음
  • 산출물: 답변, 아티팩트(문서·웹앱 미리보기)
  • 강점: 질문·초안·아이디어 정리, 가장 낮은 진입장벽
  • 한계: 내 파일시스템·장시간 작업 접근 불가
COWORK

클라우드 작업실 + 내 폴더

  • 실행 위치: 클라우드 컨테이너 (자체 파일시스템·파이썬·인터넷)
  • 파일: PC 폴더 연동으로 내 자료를 읽고 씀
  • 산출물: 수집 데이터, 보고서, 파일 수백 개짜리 파이프라인
  • 강점: 웹 수집, 대량 문서 처리, 장시간 자율 작업
  • 한계: 내 PC에서 프로그램을 "실행"하지는 못함
CLAUDE CODE

내 컴퓨터의 터미널

  • 실행 위치: 내 PC — 터미널에서 직접 명령 실행
  • 파일: 현재 폴더의 파일을 직접 읽고·쓰고·실행
  • 산출물: 실행되는 프로그램 — 서버를 켤 수 있음
  • 강점: 로컬 백엔드, 개발 워크플로, 내 환경 제어
  • 한계: 터미널이라는 낯선 환경 (오늘 극복합니다)
ChatCoworkClaude Code
AI가 일하는 곳대화창클라우드 컨테이너내 PC 터미널
내 파일 접근업로드한 파일만연동 폴더 읽기/쓰기폴더 직접 읽기/쓰기/실행
프로그램 실행—클라우드에서 실행내 PC에서 실행 (서버 가동)
어울리는 작업 길이분 단위 왕복시간 단위 자율 작업세션 단위 개발 작업
대표 작업질문·초안·요약수집·분석·문서 파이프라인백엔드·자동화 스크립트
한 줄 기억법 — Chat은 묻는 곳, Cowork는 맡기는 곳, Code는 (내 컴퓨터에서) 돌리는 곳.
2

언제 무엇을 쓰나 — 이번 프로젝트의 실전 매핑

이번 판결문 프로젝트의 각 단계가 실제로 어느 작업대에서 실행됐는지(될지) 보면 구분이 선명해집니다.

연구 아이디어 다듬기, 법리 질문, 코드북 초안 토론짧은 왕복 대화 — 실행할 것이 없음
CHAT
판결문 수백 건 수집 → 분류 → 분석 보고서인터넷 접근 + 장시간 자율 작업 + 파일 대량 생산
COWORK
임베딩 파이프라인 (API 호출 → JSON 347개 → PC 폴더 동기화)클라우드에서 API 호출, 결과는 연동 폴더로
COWORK
유사 판례 검색기의 로컬 백엔드 서버 켜기서버는 내 PC에서 계속 떠 있어야 함 → 내 PC에서 실행
CODE
왜 백엔드 실습은 Code인가 웹앱이 부를 서버는 브라우저와 같은 컴퓨터에서 계속 실행 중이어야 합니다(localhost). Cowork의 클라우드 컨테이너는 세션이 끝나면 사라지고 내 브라우저의 localhost가 아니므로, "터미널에서 서버를 켜고 유지하는" 일은 Claude Code의 영역입니다. API 키를 내 PC에만 두는 보안 구조와도 맞아떨어집니다.
3

Claude Code 시작하기 — 설치부터 첫 대화까지

설치는 터미널에 명령 한 줄입니다. Pro 이상 구독 계정이면 추가 비용 없이 로그인해서 씁니다.

1
터미널 열기

Windows: 시작 메뉴에서 PowerShell 검색 → 실행. macOS: Spotlight(⌘+Space)에서 터미널 검색 → 실행.

2
설치 명령 실행
Windows (PowerShell)
irm https://claude.ai/install.ps1 | iex
macOS / Linux
curl -fsSL https://claude.ai/install.sh | bash

터미널이 낯설면 대안도 있습니다 — Claude 데스크톱 앱에도 Code 기능이 들어 있어 그래픽 화면으로 쓸 수 있습니다.

3
설치 확인 + 로그인
확인
claude --version

버전 번호가 나오면 성공. 작업할 폴더로 이동해 claude를 입력하면 브라우저가 열리며 로그인(구독 계정)합니다. 문제가 있으면 claude doctor가 진단해 줍니다.

4
첫 대화 — 검색 서버 실습 사전 점검
💬 첫 프롬프트
파이썬이 설치되어 있는지 버전을 확인해줘. 없다면 설치 방법을 안내해줘.

Cowork와 똑같이 한국어로 대화하면 됩니다 — 다른 점은 명령이 내 컴퓨터에서 실행된다는 것뿐입니다. 실행 전에 항상 허락을 구하므로, 무엇을 하려는지 읽고 승인하세요.

내 PC에서 실행된다 = 책임도 내 PC Claude Code는 실행 전 확인을 요청하지만, 승인 버튼을 습관적으로 누르지 마세요. 특히 파일 삭제·설치 명령은 내용을 읽고 승인하는 습관이 중요합니다. 중요한 폴더는 백업 후 실습하세요.
4

마무리 체크리스트

  • Chat은 묻는 곳, Cowork는 맡기는 곳, Code는 내 컴퓨터에서 돌리는 곳
  • 구분 기준은 기능 목록이 아니라 "AI의 손발이 어디에 있는가"
  • 서버처럼 내 PC에서 계속 떠 있어야 하는 것은 Claude Code의 영역
  • Claude Code 설치 → claude --version → 폴더에서 claude → 파이썬 확인
  • 실행 승인은 읽고 누른다 — 내 PC에서 실행되는 만큼 책임도 내 쪽
다음 강의 — 두 가지 검색 패러다임먼저 키워드 검색과 임베딩 검색을 직접 써보며 "왜 백엔드가 필요한가"를 확인하고, 그다음 강의에서 오늘 설치한 Claude Code로 내 PC에 검색 서버를 켭니다.
미리 준비OpenRouter 계정과 API 키, 소액 크레딧 충전, 그리고 오늘 설치한 Claude Code에서 파이썬 실행 확인.
