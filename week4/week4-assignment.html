WEEK 4 · 종합 과제 — 부트캠프 졸업 작품

내 데이터로, 나의 자문단까지

4주차에서 만든 흐름(시트 원장 → 관리기 → 노션 일지 → 자문단)을 이번에는 내 주제로 한 바퀴 돕니다. 투자일 필요는 없습니다. 꾸준히 쌓이는 데이터라면 무엇이든 재료가 됩니다. 헤르메스 설치도 필요 없습니다. 자문단은 Claude Code의 스킬로 충분히 굴러갑니다.

1

주제 정하기 — 꾸준히 쌓이는 내 데이터

주제가 절반입니다. 세 가지 조건을 만족하는 데이터를 고르세요:

① 숫자나 기록이 주기적으로 쌓입니다 (매일이든 매주든)
② 사람이 정기적으로 들여다볼 이유가 있습니다 (보고, 결산, 점검)
③ "앞으로 어떻게 할까"를 두고 관점이 갈릴 수 있습니다 (자문단의 재료)

주제 예시원장 (시트)일지 (노션)갈리는 관점
팀 업무 지표주간 처리 건수·리드타임주간 리포트속도 우선 vs 품질 우선
개인 재정월별 지출 내역월간 결산절약 vs 삶의 질
연구·논문 진행실험 결과·진행률연구 일지실험 더 vs 이제 집필
건강·운동 기록운동량·체중·수면주간 요약강도 올리기 vs 회복 우선
민감한 데이터는 빼고 시작 실명, 계좌번호, 고객·환자 정보 같은 민감정보는 원장에 넣지 마세요. 나만 쓰는 도구여도 연동하는 순간 시트·노션·에이전트에 복제본이 생깁니다. 회사 데이터라면 회사의 보안 정책을 먼저 확인하세요.
2

데이터 면 — 시트 원장과 관리기 (②·③ 복습)

구글 시트가 원장, Claude Code로 만든 관리기가 그 위의 화면입니다.

1
시트에 원장 만들기

탭 규칙부터 정합니다. ②에서 했던 것처럼 한 파일 안에 날짜(또는 주차)별 탭으로 쌓는 방식을 권합니다. 기록 몇 개를 미리 채워 두세요.

2
관리기는 계획부터

바로 만들라고 하지 말고, ②의 요령대로 화면 계획부터 받습니다:

💬 Claude Code에게 
구글 시트에 내 [주제] 기록이 있어. 주소는 .env에 넣어 뒀어.
이 기록을 어떤 화면으로 관리하면 좋을지 계획부터 보여줘.

계획을 보고 대화로 다듬은 뒤에 만들게 하세요. 시트 주소는 곧 열쇠이니 .env에 둡니다.

3
필요해지면 서비스 계정으로

링크 공유로 시작하고, 앱이 스스로 읽어야 하는 단계가 되면 ③의 서비스 계정(뷰어 권한, JSON 키 로컬 보관)으로 업그레이드합니다.

3

협업 면 — 노션 일지 (④ 복습)

데이터가 모이는 자리(시트)와 사람이 읽는 자리(노션)를 나눕니다.

💬 Claude Code에게 
관리기에 노션 일지 기능을 붙이자. 실행할 때마다
오늘 날짜의 페이지로 요약 리포트를 하나 만들어 줘.

일지가 쌓이기 시작하면 ④의 마지막처럼 Claude Chat의 노션 커넥터로 그 데이터와 대화해 보세요. "이번 달 흐름이 어때?"가 코드 없이 되는 순간입니다.

4

자문 면 — 관점이 갈리는 봇들 (⑤~⑦ 복습 · 심화)

⑦의 구조를 내 주제로 옮깁니다. 관점 둘 + 검증 하나입니다.

시작 전에 ⑤의 점검을 한 번 돕니다: 봇이 읽는 데이터는 읽기 전용인가, 실행 권한은 없는가, 보고는 기록으로 남는가. 그 다음 §1에서 정한 갈리는 관점 한 쌍을 스킬 파일로 만듭니다:

💬 Claude Code에게 
내 [주제] 자문단 스킬 3개를 만든다. [관점 A] 담당, [관점 B] 담당, 검증 담당.
⑦에서 배운 스킬 구조(신조·데이터·규칙·출력·금지)로 초안을 만들어 줘. 내가 다듬을게.

Claude Code에서 스킬 셋을 만들어 "자문단을 소집해 줘" 한 줄로 수동 소집하면 같은 구조가 돌아갑니다. ⑥~⑦처럼 헤르메스를 직접 설치해 본 사람이라면 노션 연결과 매일 루틴까지 걸어 보세요.

과제의 핵심 질문 자문단이 정반대 제안을 동시에 내놓았을 때, 그 충돌이 내 결정에 무엇을 더해 주는지를 관찰하세요. 이 관찰이 §5 회고의 재료입니다.
5

마무리 — 제출과 회고

📦
제출물 (노션 페이지 하나에 모아서)
① 시트 원장 스크린샷 또는 링크  ② 관리기 화면 1장  ③ 노션 일지 1페이지  ④ 자문단 보고 1회분  ⑤ 한 페이지 회고: 무엇을 맡겼고, 무엇은 사람이 결정하게 남겼나

이것으로 부트캠프가 끝납니다. 4주 동안 대화에서 시작해 나만의 서비스를 배포했고, 서비스들을 연동했고, 마지막에는 관점이 다른 에이전트들을 내 데이터 위에 세웠습니다. 도구는 계속 바뀌어도 이번에 손에 익힌 원칙은 그대로 갑니다: 권한은 최소로, 비밀은 환경변수로, 자율에는 안전장치를, 결정은 사람이.
