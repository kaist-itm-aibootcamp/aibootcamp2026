WEEK 4 마지막 주차 2026년 8월 25일 (화) · 저녁 8:00–9:30

연동과 자율 에이전트 —
AI에게 일을 맡기는 법

부트캠프의 마지막 주차입니다. 자율 실행의 위험과 안전장치(프롬프트 인젝션·샌드박스·human-in-the-loop)에서 출발해, MCP 커넥터·CLI·구글 시트 연동으로 AI의 도구함을 채우고, 자가 호스팅 에이전트 에르메스(Hermes)를 설치해 텔레그램으로 부르고 cron 루틴으로 "내가 자는 동안 일하는 AI"를 완성합니다. 강의는 킥오프 시연으로 시작합니다 — 에르메스 설치 → 텔레그램 연결 → 루틴 등록을 한 흐름으로 보여드린 뒤, 자료를 순서대로 따라갑니다.

📘 강의자료 7개 🧪 실습 에르메스 설치 + 텔레그램 페어링 + 루틴 등록 🎯 산출물 매일 아침 브리핑을 보내는 나의 자율 에이전트
4주차 강의자료

원칙을 세우고, 연결하고, 맡기는 7개의 자료

①은 자율 에이전트를 들이기 전에 반드시 알아야 할 위험과 안전장치, ②~④는 AI의 도구함을 채우는 과정(MCP, CLI, 시트 연동), ⑤~⑦은 자율 에이전트를 직접 설치·운영하고 4주 전체를 판단 기준으로 접는 과정입니다. 앞 자료의 원칙이 뒤 자료의 실물로 등장하므로 순서대로 보시는 것을 권합니다.

1위험·안전장치 → 2MCP → 3CLI → 4시트 연동 → 5에르메스 설치 → 6루틴·대시보드 → 7총정리
PART 1

위험을 알고 시작한다

① · 이론
01

자율 실행의 위험과 안전장치 개념

자율 에이전트에게 열쇠를 주기 전에 잠금장치부터 — 치명적 3요소(사적 데이터·불신 콘텐츠·외부 통신)와 간접 프롬프트 인젝션의 구조, OpenClaw(2026) 실제 사례, 그리고 두 겹의 방어: 샌드박스·컨테이너 고립과 human-in-the-loop.

PART 2

AI의 도구함을 채운다

②–④ · 개념 + 실습
02

MCP(커넥터) — 연결의 표준 개념 실습

AI를 내 데이터에 연결하는 표준 규약 MCP를 이해하고, Claude의 커넥터가 곧 MCP 서버임을 확인한 뒤, Google Drive 커넥터로 내 시트를 대화에서 직접 분석해 봅니다.

→ 03

CLI — MCP가 없는 시스템을 잇는 만능 어댑터 개념 실습

통로를 만드는 대신 AI에게 도구를 쥐여주는 발상의 전환. Google Cloud CLI 제품군·ffmpeg·pandoc·ImageMagick 같은 기성 CLI를 한국어로 부리는 예시 네 가지, 그리고 레거시 시스템용 어댑터를 직접 만들어 CLAUDE.md에 꽂는 3단계까지.

→ 04

구글 시트 연동 — 읽기 전용에서 서비스 계정까지 개념 시연

"웹에 게시"로 백엔드 없이 도는 대시보드부터, 정식 출입구(Sheets API + 서비스 계정)와 열쇠 보관 원칙, 그리고 "시트는 그대로, 화면만 서비스로" 팀 현황판 활용사례까지 — 시트 연동의 전체 지도를 한 편에 담았습니다.

→
PART 3

자율 에이전트를 설치하고, 맡기고, 판단한다

⑤–⑦ · 실습 + 총정리
05

에르메스 에이전트 ① — 설치·텔레그램·OpenRouter 실습

Nous Research의 오픈소스 자율 에이전트 에르메스를 Hostinger VPS의 원클릭 템플릿으로 설치합니다 — 24시간 도는 내 서버가 생기고, 도메인까지 붙이면 개인 서버 완성. OpenRouter 키로 두뇌를 꽂고, BotFather 봇과 페어링 코드로 텔레그램을 연결합니다. ①의 안전 원칙이 실물로 등장합니다.

→ 06

에르메스 에이전트 ② — cron 루틴·대시보드 실습

매일 아침 9시, 스스로 조사해 텔레그램으로 브리핑을 보내는 cron 루틴을 등록하고, 관리 대시보드를 한 바퀴 돕니다. 그리고 솔직한 비교 — "사실 Claude로도 됩니다": 자가 호스팅이 진짜 의미 있는 네 가지 경우.

→ 07

총정리 — 판단 기준과 4주의 마무리 정리

커넥터·정적·백엔드·인증·CLI에 "루틴/자율 에이전트" 갈래를 더한 판단표 한 장, 일곱 사례 자가 점검, 난이도별 도전 과제 — 그리고 1~4주차 전체 여정의 마무리와 수료 축하까지.

→ ＋

자율 실습 — 포트폴리오 수익률 앱 선택

해 보고 싶은 분들을 위한 상세 안내입니다. 시트에 포트폴리오 원장을 만들고, 앱이 매일 시세를 수집해 기록으로 쌓아 수익률과 자산 추이 그래프를 보여주게 하고, 비밀번호 잠금까지 — 4주 동안 배운 것을 한 화면에 모으는 실습입니다.

→
강의 전 준비물

세 가지만 확인하면 됩니다

새로 만들 것은 텔레그램 봇 하나뿐이고, 나머지는 지난 3주 동안 만든 것들의 재사용입니다.

✈️ 텔레그램 계정 에이전트와 대화할 통로입니다. 폰에 텔레그램을 설치하고 로그인해 두세요. 수업 중 @BotFather로 봇을 만들어 연결합니다.
🔑 OpenRouter API 키 2·3주차에 발급한 키를 그대로 재사용합니다. 키를 어디에 적어 두었는지(예: openrouterkey.txt) 미리 확인해 두세요.
🖥️ Hostinger 계정 (VPS 호스팅) 에르메스를 올릴 VPS를 Hostinger에서 만듭니다(원클릭 템플릿, KVM 2 권장, 월 몇 달러대). 수업 전 결제까지는 필요 없고 계정만 만들어 두면 됩니다. 연결할 도메인이 있다면(1주차 것 재사용 가능) 더 좋습니다.
