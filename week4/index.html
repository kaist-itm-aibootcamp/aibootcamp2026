WEEK 4 마지막 주차 2026년 8월 25일 (화) · 저녁 8:00–9:30

연동과 에이전트 —
내 데이터와 잇고, 일을 맡긴다

부트캠프의 마지막 주차입니다. 이번 주는 내 포트폴리오 하나를 관통 예제로 씁니다. 연동의 표준 MCP와 커넥터로 시작해, 구글 시트를 장부 삼은 포트폴리오 관리기를 만들고 연결을 서비스 계정으로 격상하며, 노션으로 리포트를 발행해 사람과 공유합니다. 마지막에는 자가 호스팅 에이전트 헤르메스(Hermes)를 세우고, 관점이 다른 봇 셋의 투자 자문단에 포트폴리오 검토를 맡깁니다. 결정은 나의 몫입니다.

4주차 강의자료

연결에서 위임까지, 7개의 자료

앞 자료의 산출물이 뒤 자료의 재료가 되므로 순서대로 보시는 것을 권합니다.

PART 1

연결부터 배운다

① · 개념 + 실습
01

연동이란 — MCP와 커넥터, 연결해서 써보기 개념 실습

AI를 내 데이터에 연결하는 표준 규약 MCP를 이해하고, Claude의 커넥터가 곧 MCP 서버임을 확인한 뒤, Google Drive 커넥터를 켜서 내 시트를 대화에서 직접 분석해 봅니다. 이번 주 전체의 지도가 함께 그려집니다.

PART 2

구글 시트와 노션 — 데이터 면과 협업 면

②–④ · 실습
02

시트 읽고 쓰기 — 포트폴리오 관리기 (기초) 실습

구글 시트를 장부 삼아 포트폴리오 스냅샷을 기록하고, 링크 공유(주소가 곧 열쇠)로 프로그램이 읽는 대시보드를 만듭니다. 실제 계획 문답과 지시 기록 발췌로 "짧게 지시하고 대화로 키우는" 리듬을 익힙니다.

→ 03

서비스 계정으로 업그레이드 실습

시트를 다시 비공개로 잠그고, 프로그램에게만 열쇠(GCP 서비스 계정)를 줍니다. 실제 설정 화면 그대로 프로젝트·API 2개·서비스 계정·JSON 키를 만들고, 시트 하나가 아니라 드라이브 폴더째 공유합니다. 관리기 동작은 그대로이고 문단속만 달라집니다.

→ 04

노션 연동 — 매일 쌓이는 자산 일지 실습

지시 한 줄과 루틴으로 자산 현황·추이 그래프·종목별 수익률이 매 거래일 노션 페이지로 자동 발행됩니다. 실제로 쌓이고 있는 일지(표지 + 날짜별 페이지)를 그대로 보고, 사람과 공유하고, 폰의 Claude Chat에서 그 데이터로 대화하는 것까지.

→
PART 3

에이전트에게 맡긴다

⑤–⑦ · 개념 + 실습
05

맡기기 전에 — 자율 실행의 위험과 안전장치 개념

자율 에이전트에게 열쇠를 주기 전에 잠금장치부터. 치명적 3요소와 프롬프트 인젝션의 구조, 실제 사례 둘(공격당한 OpenClaw, 예약을 부탁받고 남의 예약을 지운 멜버른 사건), 그리고 두 겹의 방어인 샌드박스·컨테이너 고립과 human-in-the-loop.

→ 06

헤르메스 설치 — 내 에이전트 서버 실습

자율 에이전트가 실행되면 어떤 모습인지 시연으로 봅니다. 강사 PC에 로컬 설치된 오픈소스 에이전트 헤르메스에 텔레그램으로 말을 걸면, PC에서 명령이 실행되고 결과가 돌아옵니다. ⑤의 안전 원칙이 페어링 코드·컨테이너 고립으로 실물이 되는 자리이고, 이 에이전트가 ⑦의 투자 자문단을 굴립니다.

→ 07

나의 투자 자문단 — 관점이 다른 봇 셋, 결정은 나 실습

강세론·약세론·리스크검증 담당 세 봇이 노션에 매일 쌓이는 포트폴리오 일지와 웹 검색을 근거로 정반대 논거를 만들고, 반론·백테스트·몬테카를로 검증을 거칩니다. 스킬 파일 3개로 자문역을 만들고, 매일 아침 루틴으로 소집하며, 결정은 사람이 합니다.

→ ＋

종합 과제 — 내 데이터로, 나의 자문단까지 과제

부트캠프 졸업 작품입니다. 내 주제의 데이터로 시트 원장 → 관리기 → 노션 일지 → 관점이 갈리는 자문단까지 4주의 흐름을 한 바퀴 돌고, "무엇을 맡기고 무엇을 남겼나" 회고로 마무리합니다. 헤르메스 없이 Claude Code로 충분합니다.

→
강의 전 준비물

네 가지만 확인하면 됩니다

새로 만들 것은 노션 계정과 텔레그램 봇 정도이고, 나머지는 지난 3주 동안 만든 것들의 재사용입니다.

📝 노션 계정 ④에서 리포트를 발행하고 공유할 협업 도구입니다. notion.com에서 무료 계정을 만들어 두세요.
✈️ 텔레그램 계정 에이전트와 대화할 통로입니다. 폰에 텔레그램을 설치하고 로그인해 두세요. 수업 중 @BotFather로 봇을 만들어 연결합니다.
🔑 OpenRouter API 키 2·3주차에 발급한 키를 그대로 재사용합니다. 키를 어디에 적어 두었는지(예: openrouterkey.txt) 미리 확인해 두세요.
🖥️ 헤르메스 — 별도 준비 없음 ⑥은 설치 없이 시연으로 봅니다. 직접 해 보고 싶은 사람만 공식 문서를 따라 설치하면 됩니다.
