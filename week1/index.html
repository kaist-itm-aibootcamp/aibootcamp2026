웹앱 만들고 배포하기

GitHub Pages로 웹사이트를 만들어 인터넷에 배포합니다. HTML과 자바스크립트로 단순한 문서를 넘어, 계산·시뮬레이션이 실제로 동작하는 웹앱까지 만들어봅니다. 아래 자료를 순서대로 열어 Claude를 함께 띄워둔 채 따라가시면 됩니다.

📘 강의자료 5개 🎯 산출물 실제 URL로 배포된 나만의 웹앱
1주차 강의자료

순서대로 따라가는 5개의 자료

①②는 강의 중에 함께 진행하고, ③은 웹앱 실습의 본편입니다. ④는 읽을거리, ⑤는 여유가 될 때 도전하는 추가 실습입니다.

01

Agentic AI 소개 개념

지금 우리가 쓰는 AI는 왜 '에이전트'인가 — 스스로 도구를 쓰고 판단하며 움직이는 에이전틱 AI의 작동 방식을 애니메이션과 다이어그램으로 살펴봅니다.

→ 02

개인 브랜딩 사이트 만들고 배포하기 실습

브랜딩 전략을 정리하고, AI에게 요청해 나만의 소개 사이트를 만들고, GitHub Pages로 실제 인터넷 주소에 배포하는 것까지 한 번에 진행합니다.

→ 03

웹앱 만들기 실습

정적인 소개 페이지를 넘어, HTML 파일 안에 <script>로 실제 프로그램을 넣습니다. 계산·그래프·시뮬레이션이 브라우저에서 바로 동작하는 금융 플래너를 만들어봅니다.

→ 04

HTML의 압도적 효과성 읽을거리

보고서도, 계획서도, 과제도 이제는 HTML로 — 워드·파워포인트 대신 HTML 파일 하나로 문서를 만드는 활용법을 예시 프롬프트와 실제 화면으로 소개합니다.

→ 05

나만의 도메인 연결하기 추가 실습 · 선택

github.io 주소 대신 내이름.com 같은 나만의 주소를 붙입니다. 방법을 미리 알려주지 않고, Claude에게 물어보며 스스로 해결하는 연습입니다.

다음 주차

2주차 — 데이터 분석 & 백엔드 아키텍처

1주차에 만든 웹앱을 이어서 발전시킵니다. 웹에서 데이터를 모으고, 텍스트를 벡터로 바꾸는 임베딩을 배우고, 유사 판례 검색기와 RAG 챗봇을 직접 구축하며 왜 AI API에 비용을 지불하고 언제 백엔드가 필요한지 이해합니다.
