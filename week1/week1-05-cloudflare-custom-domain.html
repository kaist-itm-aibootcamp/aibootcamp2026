왜 커스텀 도메인인가

github.io 대신 내 이름의 주소를 쓴다는 것

[내아이디].github.io는 무료이고 편리하지만, 내 브랜드나 이름이 드러나지 않습니다. 도메인(domain)은 인터넷 주소에 붙는 이름표이고, 이를 구입해 내 GitHub Pages 사이트에 연결하면 내이름.com 같은 주소로 포트폴리오를 소개할 수 있습니다.

Cloudflare는 도메인을 직접 등록(Cloudflare Registrar)하거나, 다른 곳에서 산 도메인을 가져와 관리할 수 있게 해주는 서비스입니다. DNS 관리·보안·속도 개선 기능은 무료로 제공하지만, 도메인 자체는 유료입니다 (대부분 연 1만 원 안팎, .com 기준). "무료 도메인"이 아니라 "Cloudflare의 무료 DNS 관리 기능"이라는 점을 헷갈리지 마세요.

이번 실습이 다른 점

지금까지는 이 페이지가 단계를 하나씩 설명해드렸지만, 이번엔 반대로 해봅니다. 아래 프롬프트를 Claude에게 그대로 전달하면, Claude가 여러분의 상황에 맞춰 순서를 설명해줍니다. 그 답변을 보면서 실제로 따라 해보는 것이 이번 실습의 핵심입니다 — 실전에서 "이런 걸 어떻게 하는지" 궁금할 때마다 이렇게 물어보면 됩니다.

이 프롬프트를 Claude에게 그대로 물어보세요

아래 프롬프트를 복사해서 Claude(Cowork나 claude.ai 어디든 좋습니다)에게 붙여넣으세요. 도메인을 아직 안 사셨다면 그 부분부터, 이미 갖고 계시다면 연동 단계부터 안내받을 수 있습니다.

나는 코딩 경험이 없는 초보자야.
이미 만들어둔 GitHub Pages 사이트(https://[내아이디].github.io)에
내가 새로 구입할 나만의 도메인(예: mysite.com)을 연결하고 싶어.

Cloudflare를 이용해서 이 작업을 처음부터 끝까지 순서대로 설명해줘.

조건:
- 도메인을 아직 안 샀다면 어디서/어떻게 사는 게 좋은지, 예상 비용도 알려줘
- Cloudflare 계정 생성 → 네임서버 변경 → DNS 레코드 추가 →
  GitHub 저장소의 Custom domain 설정 → HTTPS 적용까지 전부 포함해줘
- 각 단계마다 실제로 클릭해야 하는 버튼이나 메뉴 이름을 구체적으로 알려줘
- 네임서버, DNS, CNAME 같은 용어가 나오면 짧게 뜻도 설명해줘
  1. 위 프롬프트를 복사해서 Claude에게 붙여넣고 답변을 받습니다.
  2. 답변에 나온 순서를 하나씩 그대로 따라 합니다 — 막히는 단계가 있으면 그 화면을 캡처해서 Claude에게 다시 보여주고 물어보세요.
  3. 연동이 끝나면 내가 산 도메인으로 접속해 내 사이트가 뜨는지 확인합니다.
참고할 점 네임서버를 바꾸거나 DNS 레코드를 추가한 직후에는 바로 반영되지 않고 최대 24~48시간 걸릴 수 있습니다. 안 될 때는 오류가 아니라 "아직 전파 중"인 경우가 많으니 몇 시간 뒤 다시 확인해보세요. 또한 도메인 등록은 유료이므로, 결제 전 가격과 자동갱신 여부를 꼭 확인하세요.
