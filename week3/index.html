검색엔진과 RAG —
서비스로 만들어 세상에 내놓기

이번 주부터 Claude Code 주간입니다 — 2주차 1강에서 설치해 둔 그 도구를 이제 본격적으로 씁니다. 재료는 2주차의 산출물, 내 PC 폴더의 판결문 347건과 임베딩 JSON 347개. 이것으로 유사 판례 검색엔진과 RAG 챗봇을 만들고, Vercel로 배포해 URL 하나로 세상에 공개한 뒤, 이메일 인증코드로 문을 답니다. 수업은 시작 킥오프 → 강의 → 완성 시연 순서로 진행합니다. 아래 자료를 순서대로 열어 따라가시면 됩니다.

📘 강의자료 7개 🧪 재료 2주차 산출물 — 임베딩 JSON 347개 🎯 산출물 인증 문이 달린 나의 판결문 RAG 챗봇 (URL 공개)
3주차 강의자료

도구 준비에서 공개 서비스까지, 7개의 자료

①은 Claude Code 온보딩 — git·gh 설치와 깃헙 레포 만들기(준비), ②~④는 검색의 두 방식 비교에서 검색엔진 구축과 RAG 챗봇까지(만들기), ⑤는 Vercel 배포, ⑥은 Long Context와 하이브리드(RAG의 대안 갈래), ⑦은 이메일 인증(내놓고 지키기)입니다. 앞 자료의 결과물이 뒤 자료의 재료가 되므로 순서대로 보시는 것을 권합니다.

1Code 온보딩 → 2검색 비교 → 3검색엔진 → 4RAG → 5배포 → 6Long Context → 7인증 실습
01

Claude Code 시작하기 — 폴더 연동과 깃헙 레포 실습

이번 주의 주력 도구를 준비합니다. 터미널에서 git·gh를 설치하고, 명령 한 줄로 브라우저가 열리며 깃헙 계정이 연동되는 것을 확인한 뒤, 2주차 산출물이 담긴 폴더를 Claude Code로 열어 지시 한 번으로 깃헙 레포를 만듭니다. 자동 승인 권한을 얼마나 줄지의 기준까지.

→ 02

판결문 검색엔진 — 키워드 vs 임베딩 개념 체험

2주차에 수집한 판결문 347건으로 두 가지 검색 방식을 직접 써 봅니다 — 키워드 매칭의 세 가지 실패를 몸으로 느끼고, 임베딩 유사도 검색으로 넘어갑니다. 페이지 안의 두 검색창은 실제로 동작하며, "왜 백엔드가 필요한가"라는 질문이 ③으로 이어집니다.

→ 03

유사 판례 검색엔진 구축 개념 실습

KIPRIS 유사 특허 검색과 같은 산업 표준 아키텍처(색인·검색 두 국면)를 이해하고, Claude Code로 판결문 347건짜리 검색엔진을 실제로 구축합니다. "계획서부터 대화로" — 비개발자가 개발을 시키는 방법, 그리고 완성 후 계획·결정·사용법을 문서로 남기는 법(PLAN·DECISIONS·README·CLAUDE.md)까지 익힙니다.

→ 04

RAG — 근거를 달아 답하는 판례 챗봇 개념 실습

검색엔진이 "문서 목록"을 돌려준다면, RAG는 검색된 문서를 AI가 읽고 근거를 달아 "답변"을 씁니다 — 오픈북 시험의 원리. 계획 문답과 챗 모델 실측을 거쳐, 근거 번호를 인용하고 모르면 모른다고 답하는 판례 챗봇을 검색 서비스 위에 실제로 얹습니다.

→ 05

Vercel 배포 — 검색기에서 챗봇까지 실습

내 PC에서만 돌던 검색기를 클라우드(Vercel)로 옮겨 URL 하나로 공유되는 서비스로 만들고(Part A), 이어서 RAG 챗봇으로 승격합니다(Part B) — 질문하면 근거 판례를 달아 답변하는 공개 서비스. "비밀은 서버에, 환경변수로"가 처음 실물이 되는 자리입니다.

→ 06

Long Context와 하이브리드 개념

RAG의 대안 갈래 — 컨텍스트 창이 백만 토큰까지 커진 지금, 검색 없이 자료를 통째로 읽히는 Long Context가 언제 성립하는지 점검합니다(모델별 컨텍스트 비교표). 요지는 통째로 싣고 전문은 골라 읽는 하이브리드까지, 세 구조의 자리와 선택 기준을 정리합니다.

→ 07

인증 실습 — 이메일 인증코드로 문 달기 실습

⑤에서 배포한 챗봇은 URL만 알면 누구나 들어옵니다. 허용된 사람만 들어오게 문을 답니다 — 이메일 6자리 인증코드, 발송은 Gmail SMTP + 앱 비밀번호로. 페이지 안의 인증 흐름 시뮬레이터로 서버의 판단을 직접 체험합니다.

→ ＋

자율 실습 — 내 웹앱 만들어 Vercel로 배포하기 선택

해 보고 싶은 분들을 위한 상세 안내입니다. 주제는 자유 — 검색엔진, RAG 챗봇, RAG 방식 문서 작성기, 또는 전혀 다른 무엇이든. 아이디어 고르기부터 계획서·문서화·배포·문 달기까지 단계별로 안내합니다.
